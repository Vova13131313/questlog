# 📜 Questlog
**Questlog** is a minimalistic desktop RPG-styled planner built with Electron & Node.js

![Questlog Screenshot](https://i.imgur.com/xmPf3WL.png)

## Features
- Quick overlay opens on Alt+Q and closes on ESC
- Quest managing (tracking statuses, deadline timers...)
- Custom categories with your icons support
- Searching and filtering
- Local storage in JSON

## Downloading

### For users
1. Go to [Releases](../../releases) tab
2. Download latest version
3. Run the file (no installation required)

### For developers
[Node.js](https://nodejs.org/) is required

```bash
# Clone repository
git clone https://github.com/Vova13131313/questlog.git

# Go to the project directory
cd questlog

# Install dependencies
npm install

# Start the app
npm start
```
